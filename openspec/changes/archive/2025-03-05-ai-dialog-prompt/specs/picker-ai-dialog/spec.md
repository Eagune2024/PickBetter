## ADDED Requirements

### Requirement: 对话框显示
系统 SHALL 在用户选中元素后显示浮动 AI 对话框，允许用户输入自然语言 prompt 描述想要的调整。

#### Scenario: 选中元素后显示对话框
- **WHEN** 用户在选择器激活状态下点击页面元素
- **THEN** 系统应显示浮动 AI 对话框
- **AND** 对话框应包含输入框和提示文字
- **AND** 对话框应自动聚焦输入框
- **AND** 选中元素应保持高亮状态

#### Scenario: 对话框内容
- **WHEN** AI 对话框显示
- **THEN** 对话框应包含标题"如何调整此元素?"
- **AND** 对话框应包含文本输入框，占位符为"描述你想要的调整（如：把按钮改成红色）"
- **AND** 对话框应包含提示文字"按 Enter 提交，ESC 取消"
- **AND** 对话框不应包含任何按钮

### Requirement: 对话框定位
系统 SHALL 使用智能定位算法将对话框放置在合适位置，优先元素外部，无空间时放元素内部。

#### Scenario: 元素右侧有足够空间
- **WHEN** 选中元素的右侧有足够空间放置对话框（视口内）
- **THEN** 对话框应放置在元素右侧，垂直对齐顶部
- **AND** 对话框与元素应保持 12px 间距

#### Scenario: 元素左侧有足够空间
- **WHEN** 选中元素的右侧无空间，但左侧有足够空间
- **THEN** 对话框应放置在元素左侧，垂直对齐顶部
- **AND** 对话框与元素应保持 12px 间距

#### Scenario: 元素外部无空间
- **WHEN** 选中元素四周都无足够空间放置对话框
- **THEN** 对话框应放置在元素内部左上角
- **AND** 对话框位置应对齐元素左上角

#### Scenario: 大元素的对话框定位
- **WHEN** 选中元素的宽度和高度都大于对话框尺寸
- **AND** 元素外部无足够空间或所有外部候选位置都超出视口
- **THEN** 对话框应放置在元素内部左上角

### Requirement: 对话框交互
系统 SHALL 支持通过快捷键操作对话框，无需鼠标点击按钮。

#### Scenario: Enter 提交 prompt
- **WHEN** 用户在对话框输入框中按下 Enter 键
- **THEN** 系统应读取输入框内容作为 prompt
- **AND** 系统应输出 prompt 和选中元素信息到 console
- **AND** 系统应关闭对话框
- **AND** 系统应返回 PICKING 状态，允许选择其他元素

#### Scenario: ESC 取消对话框
- **WHEN** 用户在对话框显示时按下 ESC 键
- **THEN** 系统应关闭对话框
- **AND** 系统应返回 PICKING 状态，允许选择其他元素
- **AND** 之前选中的元素应取消选中状态

#### Scenario: 输入空 prompt
- **WHEN** 用户在输入框为空时按下 Enter 键
- **THEN** 系统应将空字符串作为 prompt 输出到 console
- **AND** 系统应正常关闭对话框并返回 PICKING 状态

### Requirement: 对话框样式
系统 SHALL 使用深色主题的浮动对话框样式，确保在各种页面背景下可见。

#### Scenario: 对话框视觉样式
- **WHEN** AI 对话框显示
- **THEN** 对话框应使用深色背景（#1e1e1e）
- **AND** 对话框应使用浅色文字（#d4d4d4）
- **AND** 对话框应有圆角（6px）
- **AND** 对话框应有阴影效果（0 4px 12px rgba(0, 0, 0, 0.4)）
- **AND** 对话框应有内边距（12px 16px）
- **AND** 对话框最小宽度应为 280px

#### Scenario: 输入框样式
- **WHEN** 用户查看对话框中的输入框
- **THEN** 输入框应使用深色背景（#2d2d2d）
- **AND** 输入框应有边框（1px solid #3e3e3e）
- **AND** 输入框聚焦时边框应变蓝（#2196F3）
- **AND** 输入框应有圆角（4px）
- **AND** 输入框字体大小应为 14px

#### Scenario: 对话框层级
- **WHEN** 对话框显示
- **THEN** 对话框的 z-index 应为 2147483642
- **AND** 对话框应高于高亮层（2147483640）和信息标签（2147483641）
- **AND** 对话框应支持用户交互（pointer-events: auto）

### Requirement: 事件隔离
系统 SHALL 确保对话框元素不会触发选择器的事件处理（鼠标悬浮、点击）。

#### Scenario: 鼠标悬浮对话框
- **WHEN** 用户在 SELECTED 状态下将鼠标悬浮到对话框上
- **THEN** 对话框本身不应触发高亮效果
- **AND** 对话框下方的页面元素不应被高亮

#### Scenario: 点击对话框
- **WHEN** 用户在 SELECTED 状态下点击对话框或输入框
- **THEN** 点击事件不应被选择器捕获
- **AND** 输入框应正常获取焦点
- **AND** 用户应能正常输入文字

#### Scenario: SELECTED 状态下的页面交互
- **WHEN** 系统处于 SELECTED 状态
- **THEN** 用户鼠标悬浮其他页面元素时不应触发高亮
- **AND** 用户点击其他页面元素时不应触发选择
- **AND** 用户只能通过 ESC 取消对话框后才能选择其他元素

### Requirement: 状态管理
系统 SHALL 在 SELECTED 状态下保持选中元素的引用和高亮效果。

#### Scenario: 进入 SELECTED 状态
- **WHEN** 用户点击元素进入 SELECTED 状态
- **THEN** 系统应保存选中元素的引用
- **AND** 系统应保持高亮覆盖层显示
- **AND** 系统应隐藏信息标签（避免视觉冗余）

#### Scenario: SELECTED 状态下的元素高亮
- **WHEN** 系统处于 SELECTED 状态
- **THEN** 之前选中的元素应继续显示高亮效果
- **AND** 高亮覆盖层应继续覆盖该元素
- **AND** 高亮位置应与选中元素边界一致

#### Scenario: 退出 SELECTED 状态
- **WHEN** 用户通过 Enter 或 ESC 退出 SELECTED 状态
- **THEN** 系统应清除选中元素的引用
- **AND** 如果返回 PICKING 状态，信息标签应在下次鼠标悬浮时恢复显示
- **AND** 如果返回 IDLE 状态，所有覆盖层元素应被移除
